# PRODUCT.md — «Полиця»

## Довгострокова концепція

**«Полиця — твоя читацька пам'ять.»** Не трекер, а операційна система читача: одне місце,
де живе все, що людина коли-небудь читала, читає й планує прочитати, разом із контекстом
(нотатки, цитати, час, темп, місце в серії).

## Кому це зараз (V1)

Один користувач, кілька місяців щоденного використання, перевірка продуктової концепції
перед тим, як інвестувати в багатокористувацькість. Тому в V1 немає ні монетизації, ні
акаунтів, ні соціальних функцій — усе, що не є "чи працює ця читацька модель", свідомо
відкладено (розділ 47 ТЗ, дзеркалиться в `ROADMAP.md`).

## Core loop (найважливіший розділ цього документа)

```
Відкрив застосунок → Продовжив читання → Читав → Завершив сесію
   → Прогрес збережено → Історія/статистика оновились
```

Це єдиний цикл, який має бути бездоганним навіть якщо решта функцій ще сирі. Кожне рішення
про UX (кількість тапів, чи потрібна модалка, чи обов'язкове поле) оцінюється відносно того,
чи вона стоїть на шляху цього циклу.

## Статуси книги — українські підписи (single source: `src/design/i18n-labels.ts`)

| Код | Підпис |
|---|---|
| want_to_read | Хочу прочитати |
| reading | Читаю |
| finished | Прочитано |
| paused | Відкладено |
| did_not_finish | Не дочитав |
| rereading | Перечитую |

## Принципи UX (розгорнуто з ТЗ п.52-53)

- Найчастіші дії (почати/продовжити читання, оновити прогрес, додати нотатку, знайти книгу,
  змінити статус) — 1 tap з релевантного екрана, максимум 2.
- Прогресивне розкриття: просте видиме одразу, деталі видання/провенанс — за explicit tap
  "Показати деталі".
- Жодне необов'язкове поле не блокує збереження. Рейтинг/рецензія після фінішу — пропозиція,
  не форма, яку треба закрити.
- Конфлікт "більше функцій" vs "якість core loop" завжди вирішується на користь якості.

## Порожні та помилкові стани — тон

Кожен порожній екран пропонує дію, не просто констатує відсутність даних (приклади в
специфікації, розділ 39, відтворені 1:1 в `src/components/ui/EmptyState.tsx` пресетах).
Помилки мережі/провайдерів завжди українською, без технічних деталей, з working fallback
(manual entry) — розділ 40.

## Що НЕ є цілями V1 (нагадування, детально — `ROADMAP.md`)

Підписки, оплата, реклама, соцмережа, друзі, книжкові клуби, чат, AI-асистент, публічні
рецензії, portal видавця, marketplace, recommendation engine, складний cloud sync,
мікросервіси. Архітектура (`ARCHITECTURE.md`, розділ 8) не блокує жодне з цього пізніше.
