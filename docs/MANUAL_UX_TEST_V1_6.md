# MANUAL_UX_TEST_V1_6.md

POLYTSIA V1.6, Фаза 22 (DEVICE UX CHECK PREPARATION) — остання фаза майстер-ТЗ (`V1_6_SPEC.md`).
ТЗ прямо каже: "Не стверджуй, що physical-device test пройдений, якщо environment не має
device." Це середовище розробки не має фізичного пристрою (весь код пишеться й перевіряється
через `tsc`/`jest`/`eslint`/CI, без емулятора чи реального iPhone/Android) — тож цей документ є
**чек-листом для власника продукту**, не звітом про вже пройдені перевірки. Жодна клітинка
"Пройдено" нижче не позначена — це свідомо порожній шаблон.

Як користуватись: після встановлення білда (Expo Go або кастомний dev-client — `docs/V2_READINESS.md`
не стосується, дивись інструкції в корені репозиторію) пройди кожен сценарій, познач результат і,
якщо є розбіжність з очікуваним, додай короткий нотатку в колонку "Нотатки". Дата/пристрій/версія
ОС — заповнюються перед кожним прогоном, оскільки той самий сценарій вартий повторної перевірки
після значних UI-змін (наприклад, після Фази 19 Design System Extension).
