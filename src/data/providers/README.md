# providers

BookMetadataProvider та реалізації (GoogleBooksProvider, ISBNdbProvider,
SharedCatalogProvider, ManualBookProvider) — див. docs/BOOK_PROVIDERS.md.
Реалізовано в Milestone 7-8. Open Library та сім заготовок під майбутні
українські книгарні були тут до Milestone 10 fix6 — прибрані повністю
(`docs/STATUS_V1.md`), не лише вимкнені: Open Library був активним джерелом,
книгарні так і лишались недіючими заготовками без жодного офіційного API.
